# GUMA video teslimi

- `GUMA_video.mp4`: 2 dakika 44,2 saniye, 1080×1920, 30 fps, H.264/AAC, Türkçe altyazılı.
- `GUMA_kapak.jpg`: dikey kapak görseli.
- `GUMA_kaynaklar.zip`: kaynaklar, paylaşım açıklaması, SRT, font lisansları ve teknik kontrol kaydı.

MP4'ü GitHub dosya sayfasındaki indirme denetiminden indirebilirsiniz. İndirme için dosyanın gerçekten depoya yüklenmiş olması gerekir; yalnızca Codex çalışma alanında bulunması yeterli değildir.

Kaynak GUMA videosunun özgün sesi ve görüntüsü kullanılmamıştır. Genel stoklar temsili olarak işaretlenmiştir. Pexels dosya lisansları ve ElevenLabs plan hakları bağımsız doğrulanamamıştır; kaynak paketindeki kullanım notları geçerlidir. Bu çalışma hukuki sorunsuzluk veya izlenme garantisi taşımaz.

Dosyalar, kullanıcının açık onayıyla GitHub üzerinden teslim edilmek üzere hazırlanmıştır.
